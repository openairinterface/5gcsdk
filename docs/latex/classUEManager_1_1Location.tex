\doxysubsection{Detailed Description}
\begin{DoxyVerb}Represents different location-related identifiers.

This enum class provides identifiers related to the location of a User Equipment (UE),
including Cell ID and Tracking Area Code (TAC).

:cvar CELL_ID: Represents the cell ID of the UE.
:cvar TAC: Represents the Tracking Area Code (TAC) of the UE.
\end{DoxyVerb}
