\doxysubsection{Detailed Description}
\begin{DoxyVerb}Represents the registration status of a User Equipment (UE).

This enum class provides different status values for a UE, including registered, deregistered,
and error states.

:cvar REGISTERED: Indicates that the UE is registered.
:cvar DEREGISTERED: Indicates that the UE is deregistered.
:cvar UE_NOT_FOUND: Indicates that the UE was not found in the system.
:cvar INVALID_INPUT: Indicates that the input (IMSI or IP address) is invalid.
:cvar ERROR: Indicates that an error occurred while retrieving UE status.
\end{DoxyVerb}
