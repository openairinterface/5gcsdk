\doxysubsection{Detailed Description}
\begin{DoxyVerb}Represents a User Equipment (UE) with various attributes related to its state and connection.

This class encapsulates the details of a UE, such as its SUPI, IP address, and connection state.
It also includes optional attributes like PLMN, cell ID, and traffic data.

:param supi: Subscription Permanent Identifier (SUPI) of the UE.
:type supi: str
:param ad_ipv4_addr: IPv4 address of the UE.
:type ad_ipv4_addr: str
:param ran_ue_ngap_id: NGAP ID for the UE in the RAN.
:type ran_ue_ngap_id: str
:param rm_state: Registration state of the UE.
:type rm_state: str
:param timestamp: Timestamp of the last update.
:type timestamp: int
:param amf_ngap_id: AMF NGAP ID associated with the UE, defaults to an empty string.
:type amf_ngap_id: str, optional
:param plmn: Public Land Mobile Network (PLMN) identifier, defaults to an empty string.
:type plmn: str, optional
:param cell_id: Cell ID where the UE is located, defaults to an empty string.
:type cell_id: str, optional
:param sd: Slice Differentiator (SD) associated with the UE, defaults to an empty string.
:type sd: str, optional
:param sst: Slice/Service Type (SST) associated with the UE, defaults to an empty string.
:type sst: str, optional
:param dnn: Data network name associated with the UE, defaults to an empty string.
:type dnn: str, optional
:param number_pkts_dl: Number of downlink packets, defaults to an empty string.
:type number_pkts_dl: str, optional
:param number_pkts_ul: Number of uplink packets, defaults to an empty string.
:type number_pkts_ul: str, optional
:param data_ul: Total uplink data volume, defaults to an empty string.
:type data_ul: str, optional
:param data_dl: Total downlink data volume, defaults to an empty string.
:type data_dl: str, optional

:return: A UE object representing a user equipment with all its attributes.
:rtype: UE

:raises ValueError: If any of the required parameters are missing or invalid.

Usage Example:
--------------
>>> ue = UE(supi="imsi-123456789012345", ad_ipv4_addr="192.168.1.1", ran_ue_ngap_id="12345", rm_state="REGISTERED", timestamp=1627389000)
>>> print(ue)
\end{DoxyVerb}
