Detailed Description

Represents traffic volume metrics.

This enum class defines metrics for tracking the total uplink and downlink traffic volume.

:cvar TOTAL_UPLINK: Represents the total uplink traffic volume.
:cvar TOTAL_DOWNLINK: Represents the total downlink traffic volume.
