5G Core Network SDK Documentation

Introduction

This documentation provides an overview of the 5G Core Network SDK (5gcsdk), detailing its packages, usage, description, and requirements.

Packages

  • RFsimUEManager: Provides functionalities for managing simulated UEs in the RF environment.
  • UEManager: Offers functionalities for managing UEs within the 5GC network.
  • CallbackManager: Facilitates the registration and handling of event callbacks.
  • NFManager: Provides functionalities for managing network functions (NFs) within the 5GC.

Each package documentation can be accessed under the Namespaces section.

Usage

  1. Start the handler.py script to set up the Flask web application for handling AMF and SMF notifications.
  2. Import the oai5gc module.
  3. Start the OAI RFSIM5G environment using the START_OAI_RFSIM5G function.
  4. Utilize the functionalities provided by the respective packages within the SDK.

Description

This script sets up a Flask web application to handle AMF and SMF notifications, registers callback functions for various events, and updates MongoDB collections with received notifications.

Requirements

  • Flask
  • pymongo
  • requests

All requirements can be installed using the 5gcsdk/src/setup.py script.

How to Use

  1. Ensure all required packages are installed.
  2. Run the script.
  3. The Flask application will start, listening on the specified host and port.
  4. Incoming AMF notifications are handled at '/callbacks/amf-reports' endpoint.
  5. Incoming SMF notifications are handled at '/callbacks/dataplane-reports' endpoint.
